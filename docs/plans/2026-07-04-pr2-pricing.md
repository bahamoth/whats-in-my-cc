# PR-2 비용 가격표 구현 계획 (스펙 §2)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 가격표를 `pricing.json`으로 분리해 `/usage` API에 모델별 단가를 노출하고, 비용 카드 툴팁에 세션 관측 모델의 단가표+기준일을 동적 조립하며, GitHub Actions 주간 cron이 공식 가격 페이지와 대조해 갱신 PR을 자동 생성하게 한다.

**Architecture:** 가격표 SSOT는 저장소 루트 `pricing.json` 하나 — Rust는 `include_str!`+serde로 컴파일 타임 임베드(기동 시 1회 파싱, `once_cell::sync::Lazy`), 갱신 스크립트(`scripts/update-pricing.ts`)는 JSON만 재작성한다. 프론트는 API가 내려준 `rates`를 표시만 한다(하드코딩 금지). 자동화는 cron→파싱→diff→PR 생성이며 병합은 사람이 한다.

**Tech Stack:** Rust(axum·serde·once_cell·chrono), TypeScript(React·vitest), Node 22 스크립트(외부 의존성 없음, `node:test`), GitHub Actions + `gh` CLI.

**스펙:** `docs/specs/2026-07-04-session-detail-improvements.md` §2 (전체 맥락 필요 시 먼저 읽을 것).

- [ ] **Step 5: `pricing.rs` 로더 전환**

`src/insight/pricing.rs`에서 `PRICING_VERSION` 상수(29행)와 `PRICING` 상수(51~115행), `rates_for`(137~139행)를 삭제하고 아래로 교체. 모듈 헤더 주석은 유지하되 "update `PRICING` and bump `PRICING_VERSION`" 문장을 "update `pricing.json` (root) — `scripts/update-pricing.ts`가 자동화, 수동 편집 시에도 JSON만"으로 고친다. `ModelRates`·`ModelCost`·`CostEstimate`·`estimate_session_cost`·`COST_BASIS_ESTIMATE`는 그대로 둔다.

```rust
use once_cell::sync::Lazy;
use serde::Deserialize;
use std::collections::BTreeMap;

/// Checked-in pricing table (repo root). Rust embeds it at compile time so the
/// runtime NEVER fetches rates externally (local-first, spec §2.4-6);
/// `scripts/update-pricing.ts` + the weekly pricing-refresh workflow keep the
/// file in sync with the public pricing page via reviewed PRs.
static PRICING_JSON: &str = include_str!("../../pricing.json");

#[derive(Debug, Deserialize)]
struct PricingFile {
    version: String,
    source_url: String,
    models: BTreeMap<String, ModelRates>,
}

static TABLE: Lazy<PricingFile> = Lazy::new(|| {
    serde_json::from_str(PRICING_JSON)
        .expect("pricing.json: schema mismatch (spec 2026-07-04 §2.1) — version/source_url/models required")
});

/// Pricing-table provenance `pricing_estimate@<YYYY-MM-DD>` — the date IS the
/// version (last refresh from the public page; no arbitrary v-numbering).
pub fn pricing_version() -> &'static str {
    &TABLE.version
}

/// Public pricing page the table was captured from (used by the refresh
/// script/workflow and surfaced for provenance).
pub fn pricing_source_url() -> &'static str {
    &TABLE.source_url
}

/// Look up the ESTIMATE rates for a model id (exact match).
pub fn rates_for(model: &str) -> Option<ModelRates> {
    TABLE.models.get(model).copied()
}
```

```ts
function costCard(inputs: InsightInputs, t: TFunction): InsightCardModel {
  if (!inputs.usage) {
    return {
      id: 'cost', title: t('insight.cost.title'), value: '—',
      detail: t('insight.recollectUsage'), provenance: 'uncollected',
      tooltip: t('insight.cost.tip'),
    };
  }
  const u = inputs.usage;
  // §2.3 — 정적 추정 근거 + 관측 모델 단가 줄 + 가격표 기준일을 동적 조립.
  const tipLines: string[] = [t('insight.cost.tip')];
  for (const m of u.by_model) {
    tipLines.push(
      m.rates
        ? t('insight.cost.tipRateLine', {
            model: m.model,
            input: String(m.rates.input_per_mtok),
            output: String(m.rates.output_per_mtok),
            cacheRead: String(m.rates.cache_read_per_mtok),
            cacheWrite: String(m.rates.cache_creation_per_mtok),
          })
        : t('insight.cost.tipRateLineUnpriced', m.model),
    );
  }
  const versionDate = u.pricing_version.split('@')[1];
  if (versionDate) tipLines.push(t('insight.cost.tipPricingDate', versionDate));

  const unpriced = u.models_without_pricing.length > 0;
  const card: InsightCardModel = {
    id: 'cost', title: t('insight.cost.title'),
    value: formatUsd(u.estimated_cost_usd),
    detail: unpriced
      ? t('insight.cost.detailEstimateUnpriced', u.models_without_pricing.length)
      : t('insight.cost.detailEstimate'),
    provenance: 'estimated', tooltip: tipLines.join('\n'),
    drill: {
      lines: u.by_model.map(
        (m) => `${m.model}: ${m.priced ? formatUsd(m.estimated_cost_usd) : t('insight.cost.noPricing')}`,
      ),
    },
  };
  // S8 — cost has no per-turn pricing breakdown; bill ∝ cost, so the per-turn
  // billed-tokens series is an honest *shape* proxy for the cost trend.
  if (inputs.turns) {
    const spark = perTurnBilled(inputs.turns);
    if (spark) {
      card.sparkline = spark;
      card.sparklineTint = 'blue';
    }
  }
  return card;
}
```

```ts
#!/usr/bin/env node
/**
 * update-pricing — 공식 공개 가격 페이지를 파싱해 pricing.json과 대조/갱신
 * (스펙 docs/specs/2026-07-04-session-detail-improvements.md §2.4).
 *
 * Usage (repo root, Node 22+ — native TS type-stripping):
 *   node scripts/update-pricing.ts --check                # diff만 출력, 쓰기 없음
 *   node scripts/update-pricing.ts --check --markdown     # diff를 마크다운 표로(PR 본문)
 *   node scripts/update-pricing.ts --write                # 변동 시 pricing.json 재작성
 *   node scripts/update-pricing.ts --check --source tests/fixtures/pricing/real/pricing-page-2026-07-04.html
 *
 * exit 0: 성공(변동 유무 무관) · exit 1: fetch/파싱 실패(등록 모델 누락 포함).
 * wimcc 바이너리는 런타임에 절대 외부 fetch하지 않는다 — 이 스크립트(개발/CI)만.
 */
import { readFileSync, writeFileSync } from 'node:fs';
import { dirname, join } from 'node:path';
import { fileURLToPath } from 'node:url';

export type RatesJson = {
  input_per_mtok: number;
  cache_creation_per_mtok: number;
  cache_read_per_mtok: number;
  output_per_mtok: number;
};
export type PricingJson = {
  version: string;
  source_url: string;
  models: Record<string, RatesJson>;
};

const ROOT = join(dirname(fileURLToPath(import.meta.url)), '..');
const PRICING_PATH = join(ROOT, 'pricing.json');

/** 모델 id → 페이지 상 표기 후보(우선순위 순). Step 1의 fixture 관측으로 확정. */
const PAGE_ALIASES: Record<string, string[]> = {
  'claude-fable-5': ['claude-fable-5', 'Claude Fable 5'],
  'claude-mythos-5': ['claude-mythos-5', 'Claude Mythos 5'],
  'claude-opus-4-8': ['claude-opus-4-8', 'Claude Opus 4.8'],
  'claude-opus-4-7': ['claude-opus-4-7', 'Claude Opus 4.7'],
  'claude-sonnet-4-6': ['claude-sonnet-4-6', 'Claude Sonnet 4.6'],
  'claude-haiku-4-5-20251001': ['claude-haiku-4-5-20251001', 'claude-haiku-4-5', 'Claude Haiku 4.5'],
};

/** HTML → 공백 정규화 텍스트. */
export function htmlToText(html: string): string {
  return html
    .replace(/<script[\s\S]*?<\/script>/gi, ' ')
    .replace(/<style[\s\S]*?<\/style>/gi, ' ')
    .replace(/<[^>]+>/g, ' ')
    .replace(/&amp;/g, '&')
    .replace(/&lt;/g, '<')
    .replace(/&gt;/g, '>')
    .replace(/&nbsp;/g, ' ')
    .replace(/\s+/g, ' ');
}

/**
 * 모델 표기 등장 지점 이후 창(window)에서 `$N / MTok` 4개를
 * [input, cache-write, cache-read, output] 순서로 뽑는다(공식 표 열 순서 —
 * 동결 fixture 테스트가 이 가정을 잠근다; 페이지 개편 시 테스트가 red).
 * 등록 모델이 하나라도 안 보이면 throw.
 */
export function parsePricingPage(html: string, modelIds: string[]): Record<string, RatesJson> {
  const text = htmlToText(html);
  const out: Record<string, RatesJson> = {};
  for (const id of modelIds) {
    const aliases = PAGE_ALIASES[id] ?? [id];
    const at = aliases.map((a) => text.indexOf(a)).find((i) => i >= 0);
    if (at === undefined) throw new Error(`model not found on page: ${id} (aliases: ${aliases.join(', ')})`);
    const window = text.slice(at, at + 600);
    const dollars = [...window.matchAll(/\$\s*([0-9]+(?:\.[0-9]+)?)\s*\/\s*MTok/gi)].map((m) =>
      Number(m[1]),
    );
    if (dollars.length < 4) {
      throw new Error(`expected >=4 "$N / MTok" rates near ${id}, got ${dollars.length}`);
    }
    const [input, cacheWrite, cacheRead, output] = dollars;
    out[id] = {
      input_per_mtok: input,
      cache_creation_per_mtok: cacheWrite,
      cache_read_per_mtok: cacheRead,
      output_per_mtok: output,
    };
  }
  return out;
}

const RATE_KEYS = [
  'input_per_mtok',
  'cache_creation_per_mtok',
  'cache_read_per_mtok',
  'output_per_mtok',
] as const;

/** 등록 모델 한정 비교 — 변경 줄 목록(빈 배열 = 무변동). */
export function diffRates(current: PricingJson, parsed: Record<string, RatesJson>): string[] {
  const changes: string[] = [];
  for (const [id, cur] of Object.entries(current.models)) {
    const next = parsed[id];
    for (const k of RATE_KEYS) {
      if (next[k] !== cur[k]) changes.push(`${id}.${k}: ${cur[k]} -> ${next[k]}`);
    }
  }
  return changes;
}

function toMarkdown(changes: string[], sourceUrl: string): string {
  const rows = changes.map((c) => {
    const m = c.match(/^(.+)\.(\w+): (.+) -> (.+)$/)!;
    return `| \`${m[1]}\` | ${m[2]} | $${m[3]} | $${m[4]} |`;
  });
  return [
    '## 공개 가격표 변동',
    '',
    `출처: ${sourceUrl}`,
    '',
    '| model | rate | before | after |',
    '|---|---|---|---|',
    ...rows,
    '',
  ].join('\n');
}

async function main(): Promise<void> {
  const args = process.argv.slice(2);
  const write = args.includes('--write');
  const markdown = args.includes('--markdown');
  const srcIdx = args.indexOf('--source');

  const current: PricingJson = JSON.parse(readFileSync(PRICING_PATH, 'utf8'));
  let html: string;
  if (srcIdx >= 0) {
    html = readFileSync(join(ROOT, args[srcIdx + 1]), 'utf8');
  } else {
    const res = await fetch(current.source_url, {
      headers: { 'user-agent': 'wimcc-pricing-refresh (github.com/bahamoth/whats-in-my-cc)' },
    });
    if (!res.ok) throw new Error(`fetch ${current.source_url}: HTTP ${res.status}`);
    html = await res.text();
  }

  const parsed = parsePricingPage(html, Object.keys(current.models));
  const changes = diffRates(current, parsed);

  if (markdown) {
    console.log(changes.length ? toMarkdown(changes, current.source_url) : '변동 없음.');
  } else {
    console.log(changes.length ? changes.join('\n') : 'no drift');
  }

  if (write && changes.length) {
    const next: PricingJson = {
      ...current,
      version: `pricing_estimate@${new Date().toISOString().slice(0, 10)}`,
      models: Object.fromEntries(
        Object.keys(current.models).map((id) => [id, parsed[id]]),
      ),
    };
    writeFileSync(PRICING_PATH, `${JSON.stringify(next, null, 2)}\n`);
    console.error(`pricing.json updated: ${next.version}`);
  }
}

// node --test가 import할 때는 실행하지 않는다.
if (process.argv[1] && import.meta.url === new URL(`file://${process.argv[1]}`).href) {
  main().catch((e) => {
    console.error(String(e));
    process.exit(1);
  });
}
```
