Security & Governance Spec

로컬 고신뢰 수집을 안전하게 운영하기 위한 collection profile, redaction, retention, export governance를 정의한다.

SecurityRedactionLocal-first

01Security Stance

이 서비스는 개인 로컬 환경에서 고신뢰 데이터를 수집한다. collection level은 높아도 되지만, 수집된 데이터에는 source code, command output, token, private path, secrets가 포함될 수 있으므로 local binding, redaction, retention, export control은 제품 핵심 요구사항이다.

기본 방침: 높은 수집 수준은 허용하되, 네트워크 노출과 raw export는 보수적으로 제한한다. 로컬 insight를 위한 수집과 외부 전송 가능성을 엄격히 분리한다.

02Collection Profiles

ProfileIncludesDefaultRisk
metadata_onlytimestamps, source type, ids, status onlyNoLow
local_transcripttranscript messages, tool call/result metadataNoMedium
local_full_evidencetranscript, tool input/output, OTel metrics/logs/traces, hook payloads, file/git diff hunks, verification outputYesHigh but local
raw_api_bodyraw model/API request and response bodiesExplicit opt-in proposedVery high

Default recommendation

local_full_evidence를 기본으로 둔다. 단, raw_api_body는 별도 explicit opt-in으로 둔다.

Reason

로컬 insight 품질을 위해 tool I/O, OTel trace, diff hunk가 필요하다. raw API body는 replay 이상의 민감도를 가진다.

03Local Access Boundary

Bind

기본 127.0.0.1. 0.0.0.0 금지, unless explicit advanced setting.

Origin validation

HTTP/MCP endpoint는 Origin header allowlist를 검증한다.

Local token

Pull API와 MCP endpoint 모두 local auth token을 요구한다.

network exposure defaultlocalhost only

10피드백 필요 사항

  1. raw API body를 default off로 두는 제안을 확정할지 결정 필요.
  2. retention 기본값을 30/180/90일로 둘지, 무기한 로컬 보존 옵션을 기본으로 둘지 결정 필요.
