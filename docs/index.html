01문서 세트 개요

이 산출물은 기존 PRD를 로컬 구동 기반의 실행 인텔리전스 서비스로 재정렬한 HTML 문서 세트다. 외부 연동은 Pull API와 MCP Streamable HTTP를 우선하며, 외부 시스템이 finding이나 resource에 쓰기 작업을 하는 구조는 제거했다.

PRD 수정

annotation 관련 요구사항 제거. OTel, local full evidence, read-only resource serving을 핵심 요구사항으로 승격.

설계 분리

Product, Architecture, Data Model, API/MCP, Security, MVP Plan으로 분리.

시각화 우선

HTML 기반 swimlane, animated pipeline, SVG graph, Gantt, metric chart 포함.

로컬 우선

127.0.0.1 바인딩, high-fidelity local collection, secret redaction, owner-controlled export.

05기준 문서와 외부 기준

기준 PRD는 업로드된 What's in My Claude Code — Feedback Resource PRD다. MCP 문서에서는 Streamable HTTP가 POST/GET 기반이며 SSE를 통한 streaming이 가능하다는 점, 그리고 로컬 서버는 Origin 검증과 localhost 바인딩이 중요하다는 점을 설계에 반영했다. Claude Code OTel 문서에서는 metrics, logs/events, traces가 source layer로 사용될 수 있다는 점을 반영했다.
